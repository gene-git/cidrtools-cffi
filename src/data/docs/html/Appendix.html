3. Appendix

3.1. Installation

On Arch you can build using the provided PKGBUILD in the packaging directory or from the AUR. To build manually, clone the repo and :

rm -f dist/*
./scripts/do-build
./scripts/do-install [destination]

The default destination is build/pkg.

3.2. Dependencies

Run Time :

  • cidrtools

  • python-cffi

  • python (3.14 or later)

Building Package :

  • git

  • meson

  • meson-python

  • uv

  • python-uv-build

  • rsync

  • python-pytest

  • python-pytest-asyncio
