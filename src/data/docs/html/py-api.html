2. API Reference

This section contains the API documentation for the cidrtools package.

2.1. class cidrtools

cidrtoolls-cffi provides the cidrtools module using the fast C-code cidrtools library:

  • public class/member functions

  • wrapper function for each cidrtool ct_xx function.

class cidrtools.CidrBlock(cidr_str: str)

Bases: object

Class to manage one cidr block. Uses cidrtools C-library CtCidrBlock structure.

Handles memory allocation, type inspections, range mapping, and contains (is-subnet).

Built on the cidrtools library.

Returns:

True on success otherwise False

fix_host_bits() → int

Cleans up cidr with host bits set, by setting all host bits to zero.

format_host_bits() → str

Returns a formatted “address” string of the host bits Identical to get_host_bits() -

get_host_bits() → str

Extracts the underlying address portion - these are thr bits past the network bits defined by the prefix length.

<prefix length of network-bits … ><host-bits>

E.g. 10.2.2.3/24 => 0.0.0.3 Note that the host bits are tracked internally but the cidr is always “fixed” Example: - cidr = CidrBlock(“192.168.1.22/24”) - str(cidr) –> “192.168.1.0/24” - cidr.get_host_bits() –> “0.0.0.22”

class cidrtools.CidrBlocks(initial_cidrs: list[str] | None = None)

Bases: object

An ordered list of CtCidrs

A list of cidr blocks. Supports a variety of operations via the member functions such as: - compacting - filtering (excluding), - slicing, - cleaning.

Built on the cidrtools library. Manages memory allocations.

add(cidr: CidrBlock | str) → bool

Appends a CIDR block to the collection.

Parameters:

cidr – The cidr block (object or raw string) to add.

Returns:

True if the append succeeded else false.

clean() → bool

Clean any invalid cidr blocks (prefix, host bits being set)

Returns:

True if success else False

compact() → int

Compress the list of cidrs to the mimimal number of subnets.

This combines adjacent or overlapping subnets to make the smallest number of subnets. This is done in place.

Returns:

Return status code from the underlying C function.

exclude(excluded_cidrs: CidrBlocks) → int

Exclude a set of cidr blocks. This is done place.

new cidrs => cidrs - excluded_cidrs.

Parameters:

excluded_cidrs – The cidrs to be excluded.

Returns:

Return status code of the underlying C library.
